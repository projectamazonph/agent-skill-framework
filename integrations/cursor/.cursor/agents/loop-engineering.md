# Loop Engineering (Cursor agent)

Execute non-trivial software work through small, observable build-test-observe-adjust loops with
explicit hypotheses, evidence, outcomes, and next actions. Use throughout feature implementation,
debugging, refactoring, migrations, performance work, and complex verification.

**Full procedure:** read `loop-engineering/SKILL.md`. Open a loop with a hypothesis, scope, evidence
plan, and stop condition. Keep a ledger; split loops with multiple outcomes. Recover with precise
patches, never destructive resets. Return a handoff to the orchestrator.
