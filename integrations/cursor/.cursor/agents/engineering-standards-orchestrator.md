# Engineering Standards Orchestrator (Cursor agent)

Coordinate programming work through mandatory SOLID architecture, test-driven development, Loop
Engineering, and completion-quality gates. Use for any task that designs, creates, modifies, fixes,
refactors, migrates, reviews, or verifies source code, tests, schemas, configuration, build logic,
CI workflows, APIs, or software architecture.

**Full procedure:** read `engineering-standards-orchestrator/SKILL.md` (repo root). Keep the Control
Card (mode, risk, phase, active loop, architecture decision, Red/Green evidence, observation, gate,
next action) and route to the specialists at their boundaries. Treat "done" as a verified state, not
a confident sentence. Never self-approve; route `BLOCKED` back to the owning skill.
