# Research and Verification

Establishing credibility before reporting claims — especially on current, niche, or contested topics.

## When to use this

The user asks for factual claims, market data, technical comparisons, or anything where accuracy is hard to verify independently.

## Research discipline

1. Name the authoritative source(s) for the claim.
2. Distinguish between established fact and interpretation.
3. Note the recency of the source and whether the landscape may have shifted.
4. Flag when no reliable source supports a commonly held belief.

## Web search guidance

- Use the `web-search` tool for current events, product info, pricing, and anything time-sensitive.
- Search in English by default; include local language terms if relevant.
- Check at least two independent sources for consequential claims.
- Log the query used so the search can be reproduced or refined.

## Verification pattern

For every material claim:

```
Claim:        [exact statement]
Source:       [authoritative source name, URL, date]
Confidence:   [high / medium / low — with reason]
Gap:          [what source does not cover, if anything]
```

## What not to do

- Do not present speculation as fact.
- Do not cite vendor marketing as independent evidence.
- Do not use old data without noting the date.
- Do not invent specific numbers or citations.
- Do not discard contradictory evidence.

## Confidence levels

- **High** — authoritative primary source, recent, reproducible.
- **Medium** — secondary source, some gaps, or recency uncertain.
- **Low** — anecdotal, contested, or only one source available.

When confidence is low, say so and explain why. Ryan values honesty over false certainty.
