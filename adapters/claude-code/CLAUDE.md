# Agent Skill Suite Adapter

Read and follow `AGENTS.md` at the repository root.

Project skills live in `.claude/skills/<skill-name>/SKILL.md`. Install the folders from this suite's `skills/` directory there, or install them in `~/.claude/skills/` for user-wide access.

Use `/suite-orchestrator` for multi-stage work. Load specialist skills only when routed or directly relevant.
